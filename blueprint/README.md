# WELCOME HOME 청사진 이름 공개 페이지

별도 경로 `/blueprint/`에 추가된 모바일 우선 참여 페이지입니다. 기존 기도 누적 페이지와 기존 `add` API 동작은 유지합니다.

## 동작

- 이름 등록은 기존 Apps Script 웹앱으로 전송됩니다.
- 이름 10개가 등록되면 서버 상태에 개봉 예정 시각(현재 시각 + 20초)을 한 번 기록합니다.
- 모든 접속자는 2.5초마다 서버 상태를 확인하고 같은 개봉 시각을 기준으로 상자 애니메이션을 봅니다.
- 이름과 상자/청사진은 모든 방문자에게 공개됩니다.
- 요청 ID로 동일 요청의 재전송을 중복 처리하지 않도록 합니다.
- 이 페이지는 이름만 저장하며, 이름 외의 개인정보를 요구하지 않습니다.

## 배포

1. GitHub 변경사항을 기본 브랜치에 병합합니다.
2. Apps Script 프로젝트에서 `server/Code.gs` 변경사항을 기존 스크립트에 반영합니다.
3. Apps Script에서 **배포 → 배포 관리 → 수정 → 새 버전**으로 재배포합니다. 기존 웹 앱 URL은 유지합니다.
4. 배포된 사이트에서 `/blueprint/` 경로를 엽니다.

## 주의 사항

- 이 저장소 변경만으로는 Google Apps Script 배포본이 자동 갱신되지 않습니다.
- Apps Script는 공유 스프레드시트에 `blueprint_names` 시트를 생성합니다.
- 현재 설계는 한 번의 행사에서 하나의 청사진을 완성하는 용도입니다. 재설정/새 라운드는 관리자 기능으로 별도 구현해야 합니다.
- 이름은 공개 표시되므로 참여자에게 이를 알리고, 공개해도 되는 이름만 입력하도록 안내합니다.
- Google Apps Script의 사용량 한도와 네트워크 지연에 따라 갱신 시점은 약간 달라질 수 있습니다.
